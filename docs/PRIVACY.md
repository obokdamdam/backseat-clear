# 뒷자리 맑음 개인정보 처리방침

시행일: 2026-11-17 · 만든 곳: 오복담담소프트(개인 개발)

## 1. 한 줄 요약
뒷자리 맑음은 **서버가 없는 앱**입니다. 모든 정보는 차 안(앱 저장 공간)에만 저장되고, 밖으로 보내지 않습니다.

## 2. 저장하는 정보
| 무엇 | 왜 | 어디에 | 얼마나 |
|---|---|---|---|
| 자리별 별명(예: 「뒷자리 왼쪽」), 멀미 민감도 | 사람에 맞춰 예보를 일찍 잡으려고 | 차 안 앱 저장 공간 `family.json` | 지울 때까지 |
| 최근 30번 길의 목적지 이름·걸린 시간·멀미 날씨·「속이 안 좋아」 횟수·쉬어 간 횟수 | 도착 리포트와 다음 예보에 쓰려고 | 차 안 `trips.json` | 최근 30개만 남기고 자동 삭제 |

## 3. 저장하지 않는 정보
- **위치·이동 경로**: 내비가 준 경로로 그때그때 예보를 계산하고 저장하지 않습니다. 앱은 위치 권한을 요청하지 않습니다.
- **휴게소 근접 알림**: 「응」으로 고른 휴게소의 좌표(내비가 알려 줌)를 차량 위치 서비스(Pleos FusedLocation)에 넘겨 「가까워졌다」는 알림만 받습니다. 좌표와 내 위치는 앱에 저장하지 않습니다.
- **목소리**: 「속이 안 좋아」·「응」을 알아듣는 데만 쓰고(차량 음성 인식 SDK), 녹음·저장하지 않습니다. 마이크는 앱이 물을 때 8초만 켭니다.
- **운전 정보**(차속·브레이크·조향): 그 순간의 안내·조치에만 쓰고 저장하지 않습니다.
- **이름·나이·연락처·계정**: 받지 않습니다. 회원가입이 없습니다.

## 4. 아이의 정보
아이 이름이나 나이를 묻지 않습니다. 자리 이름이나 보호자가 정한 별명만 씁니다.

## 5. 다른 곳에 주거나 맡기지 않습니다
제3자 제공·처리 위탁이 없습니다. 광고·분석·오류 수집 도구를 넣지 않았습니다.

## 6. 쓰는 외부 SDK
| SDK | 하는 일 |
|---|---|
| Pleos Vehicle | 좌석 탑승·공조·창문·브레이크·조향 읽기/제어 |
| Pleos NaviHelper | 내비 경로·회전 안내·도착 정보 받기, 휴게소 검색 화면 열기 |
| Pleos FusedLocation | 고른 휴게소에 가까워지면 알림(근접 알림) |
| Pleos TextToSpeech · SpeechToText | 음성 안내(미리 만든 음성 파일이 없을 때) · 짧은 대답 인식 |
| Android Jetpack(Compose 등) | 화면 |

## 7. 지우는 방법
앱 → 「우리 가족」 → **「기록 모두 지우기」**(두 번 눌러 확인). 앱을 지워도 모두 사라집니다.
